The problem

The model that keeps your data cannot keep your context.

A hosted model strong enough for this job needs target names, banners, credentials and raw tool output sent to a third party. An engagement contract usually forbids that.

A local model keeps the data. It also runs out of room. One real request overflowed the server's own window by about 1300 tokens while still fitting the agent's estimate.

The agent loop

Six nodes, one loop, one budget check.

Click any node.

The agent is a LangGraph state machine with six nodes: think, act, extract, route, remember and respond.

State persists across submissions within one process through a checkpointer.

think

The only node that talks to the model. History is compacted against the context budget here, before the call is made.

The findings summary injected alongside it is rebuilt fresh every think() call from graph state rather than chat history.

act

Each proposed call runs the action guardrail chain first. The tool executes only if every stage allows it.

At most 4 model turns run per user turn.

depg_update

Successful tool results become graph nodes and edges through a per tool extractor, each carrying the quoted output that justifies it.

phase_router

Proposes the next phase. The state machine accepts it only if the transition table allows it.

memory_update

This step's findings, failures, narration and phase changes upsert into the tiered memory store.

respond

The output guardrail runs on the final text, then the run ends.

The budget

No generic local tokenizer exists, so the estimate is 3 characters per token with 4 tokens of overhead per message. 512 tokens stay reserved for the answer.

The window

The default window is 32768 tokens. The system prompt is subtracted first, because it is sent on every turn.

The cascade

Each tier runs only when the one before it still did not fit. Full history stays in state. This only shapes what is sent to the model.

Phase lock

An illegal phase jump is not reachable.

Six phases, one choke point.

Every phase change goes through PhaseStateMachine.transition(). Nothing else may move the phase.

Dashed arcs are the legal pivots back. Reporting accepts only itself.

recon

vulnerability discovery

Reporting is terminal. Its only legal next phase is itself.

Guardrails

Nothing spawns before every stage allows it.

  1. 01ScopeGuardStageBlocks a call whose target falls outside the declared engagement scope, a CIDR and domain allowlist.
  2. 02DangerousFlagGuardStageBlocks free form flags that could read or write outside the scratch directory, or trigger code execution.
  3. 03PhaseToolGuardStageRe-checks the tool against the current phase allowlist at call time, not at registration time.
  4. 04ToolOutputScreenStageScreens tool output for prompt injection markers before it is fed back into the model.
  5. 05OutputRedactionStageRedacts credentials and secrets from the final answer the operator sees and exports.

The catalog fails closed. A tool that writes, executes or destroys is registered but unreachable in every phase until someone adds an explicit phases key.

Dependency and error propagation graph

Every finding carries the output that proves it.

Click any node.

The graph merges proposed nodes and edges, resolves each dirty node's state, then prunes fully dead regions.

Identity before merge

Targets are normalized before they become part of a node's identity, so 10.0.0.5, ssh://10.0.0.5:22 and 10.0.0.5. collapse onto one node family instead of fragmenting.

Grounded evidence

Each node carries the quoted tool output that justifies it. An extractor that cannot find its own quote in the tool text is clamped to the lowest tier.

Propagation

A disproved precondition invalidates its dependents. The graded policy propagates a continuous score with a noisy OR over parents and is opt in.

Transfer and reach

generality is the share of this run's targets that already produced this cause class. downstream is the descendant count.

A disproved precondition blocks what depended on it. Pruning then collapses the region that is fully dead, so a wrong early branch does not stay in the operator's view.

Tiered memory

Memory decays unless the run keeps hitting it.

Each item carries a tier, the phase it was seen in, a snippet and a salience score.

A recurring narration or tool failure collapses onto one row and increments its hit count instead of filling the view.

Tier weight sets the starting height. The hit bonus is what lifts a row back up.

S = w_tier · s₀ · e^(−λ·age) + β·hits

Observed failure modes

Three failures we are reporting, not hiding.

  1. Failure 01A tool offering turn answered with a question The model asks for the target address when that address already sits in the instruction and the system prompt. A bounded retry was implemented and then reverted, because a discarded attempt's tokens leaked into the operator's transcript. Six tests caught the regression. The fix belongs in the streaming path.
  2. Failure 02A placeholder passed as a real argument The model invoked the port scanner with the literal placeholder token as the target, producing a real call that failed at name resolution. Remedy: an argument validation stage that rejects placeholder shaped arguments before execution.
  3. Failure 03Silent unavailability under a stalled phase When an early call produces no finding, the phase never advances past reconnaissance, so a later request for an injection tool cannot be satisfied. The operator received no signal. The most operationally significant of the three. Remedy: a visible signal, not a silent substitution.

Offline validation against clean sample output is insufficient for this class of system.

Limits and next phase

Every limit names the seam it extends into.

What the work does not claim

  • Evaluation used a single target application and a single model family.
  • Checkpointed state does not survive a process restart.
  • The dangerous argument stage is a denylist, so an unanticipated argument form is permitted by default.
  • The sandbox shares the host network, so scope is enforced on argv text and not at the operating system boundary.

Future work, highest impact first

  • Make a discarded model attempt invisible to the event stream.
  • Add an argument validation guardrail stage.
  • Replace the denylist with an allowlist grammar per tool.
  • Implement network egress control for the sandbox.
